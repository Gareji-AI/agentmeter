# ご本人の顔・声を撮るときのメモ

操作映像は別撮り済みです。画面の再操作は不要です。完成予定は2分50秒。
英語の読み上げ原稿は `narration-english.txt`、時刻付きの原本は `demo-plan.json`。
実際に撮った操作と、実装で確認したことだけを説明する内容です。

## 撮り方

1. `delivery/presenter-rehearsal.html` をブラウザで開き、無音動画と章ごとの英語を確認します。
2. スマホまたはWebカメラで、ご本人の顔と声だけを撮影します。横向き1080p・30fps、目線はレンズの近く、背景は簡単なものにします。
3. 最初と最後に3秒ほど無言の余白を入れます。音楽は入れません。マイクは口の近くに置き、エアコンなどの雑音を減らします。
4. 原稿は毎分120〜130語程度。章ごとに撮ってもかまいません。言い直すときは2秒ほど空けて、その文の頭から読み直してください。
5. 撮れた動画ファイルをこのチャットに渡してください。元ファイルを保ち、言い直しや無言部分を編集し、画面と同期して顔を右下へ配置します。重要な金額や領収記録に重なる場面では顔を小さくするか位置を調整します。

継続して1本撮るなら3〜4分ほどの素材で十分です。全体を一度で完璧に読む必要はありません。
顔・声が届くまでは、無音操作版と合成用の準備までが完了した状態です。

## 編集で守る点

- 操作間の待機はハードカットで短くします。実際のモデル応答部分は等速です。
- Codexの通信処理自体は画面外で実行し、その前後の実画面と保存された領収記録を見せています。モデルが自律的にツールを選んだとは説明しません。
- 最初の資金フローは模擬決済。最後の証拠シーンは別のRender上の実sandbox記録です。両方とも実際のお金ではありません。
- 請求書の$120は入力文の金額です。ツール利用料金は$0.01です。請求書そのものを支払ったとは説明しません。
- 公開されているサンプルAPIを例にしています。独自OCRや実際の請求書承認の実装は主張しません。
- 字幕SRTは読み上げの目安。実際の話す速さに合わせ、顔映像が届いてから再調整します。
- 最終出力は全編再生し、英語・180秒未満・秘密情報が映っていないこと・金額と状態を確認してから公開します。

`add-presenter.py` は長さのそろった顔素材を右下に重ねるローカル合成の補助です。
章ごとの素材や言い直しがある場合は、先にこちらで同期・編集してから使います。
YouTubeへの公開やDevpostへの送信は、この撮影作業では行いません。
